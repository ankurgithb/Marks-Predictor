A Machine Learning project that predicts student final grades (G3) using Linear Regression.

Features Used:-

Mother's Education (Medu)
Father's Education (Fedu)
Age
Social Activity (goout)
First Period Grade (G1)
Second Period Grade (G2)
Past Failures (failures)
Technologies Used:-

Python
pandas
NumPy
scikit-learn
matplotlib
#Model Used:-

Linear Regression

#Evaluation Metrics:-

MAE (Mean Absolute Error)
MSE (Mean Squared Error)
RMSE
R² Score
